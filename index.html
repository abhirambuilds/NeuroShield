Project Overview

What is NeuroShield?

A research-grade ML prototype that investigates whether behavioral and HCI features can reliably distinguish cognitive workload levels using multiple classification paradigms.

Behavioral Analysis

Analyzes mouse movement, keyboard patterns, and HCI signals to detect shifts in cognitive workload without invasive physiological sensors.

Multi-Model Comparison

Systematically compares LDA, Bayesian Logistic Regression, Linear SVM, and Kernel SVM under identical conditions to reveal each model's strengths.

Uncertainty Quantification

Goes beyond deterministic predictions by using Bayesian posterior distributions to quantify prediction uncertainty for each test observation.

Dataset Pipeline

Full end-to-end pipeline: Kaggle dataset ingestion, exploratory analysis, group-aware train/test splits, preprocessing, model training and evaluation.

Four Classification Approaches

Each model brings a different statistical philosophy to the cognitive workload classification challenge.

01
Linear

LDA

Linear Discriminant Analysis

Finds a linear combination of features that maximally separates the cognitive workload classes. Acts as the linear statistical baseline, assuming Gaussian-distributed features within each class.

Bayesian LR

Bayesian Logistic Regression

Extends logistic regression by placing prior distributions over coefficients and sampling posterior distributions via MCMC (PyMC). Provides uncertainty estimates per prediction unique among the four models.

Uncertainty-aware PyMC + MCMC Posterior sampling

Linear SVM

Linear SVM

LinearSVC (Optimized Linear SVM)

Uses LinearSVC for scalable linear classification on the large 57k+ training set. Finds a maximum-margin hyperplane to separate workload classes. Faster than kernel methods on high-dimensional data.

Max-margin Scalable (57k obs) C=1.0

Non-Linear

Kernel SVM

Radial Basis Function SVM

Projects data into an infinite-dimensional feature space via the RBF kernel, enabling non-linear decision boundaries. Trained on a 5,000-observation subset due to O(n^2) complexity, then evaluated on the full test set.

RBF kernel Non-linear boundary 5k train subset

Bayesian Posterior Uncertainty
